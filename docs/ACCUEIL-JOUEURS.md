# Message d'accueil des joueurs

À envoyer sur WhatsApp le jour du lancement. Remplacer l'adresse, et adapter le ton.
Il ne dit rien des règles cachées du jeu (délais, ce que deviennent les lettres).

---

Bonjour à tous,

La correspondance est ouverte. Tout se passe ici :

👉 **https://ADRESSE-DU-SITE**

**Pour entrer**
1. Saisissez l'adresse e-mail que vous m'avez donnée.
2. Vous recevez un e-mail (regardez aussi dans les indésirables) : ouvrez son lien, ou recopiez son code à 6 chiffres.
3. Vous restez connecté ensuite. Pas de mot de passe.

**Sur votre téléphone, installez le site : c'est bien plus agréable**
- iPhone : ouvrez le site dans Safari, touchez le bouton Partager, puis « Sur l'écran d'accueil ». Ouvrez-le ensuite depuis sa nouvelle icône.
- Android : ouvrez le site dans Chrome, touchez le menu ⋮, puis « Ajouter à l'écran d'accueil » (ou « Installer l'application »).

**Pour être prévenu quand un pli arrive**
À la première connexion, le site vous propose une notification sur votre appareil, un e-mail, ou les deux. Sur iPhone, les notifications ne marchent qu'une fois le site installé. Vous pourrez changer d'avis à tout moment, dans l'onglet « Personnage ».

**Ce qu'il faut savoir**
- Tout ce qui est en jeu se passe sur le site ; le hors-jeu reste ici, sur WhatsApp.
- Une lettre envoyée est partie : vous n'en gardez pas de copie.
- Vous avez un nombre limité de lettres par semaine. Choisissez bien vos mots.

En cas de souci pour vous connecter, écrivez-moi ici.

Bonne correspondance !
